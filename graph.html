使い方 x 以外の文字（n, a など）は自動でスライダーになります。y は縦の座標、i は虚数単位です。
y+25=x^2 のように = を使った式や、x^2+y^2=r のような陰関数も描けます（先頭の y= は付けたままでも OK、X・Y の大文字も可）。
各式の下に「解」を複素数まで表示します。右上の ℂ で複素数平面に切り替えると、解の位置と値の色分けが見られます（解の行をタップでも移動）。
右上の 4D で、普通のグラフがそのまま 4 次元の面に広がります（x も y も複素数、three.js）。式やスライダーを変えると 4D もすぐ変わります。左上の ⚙ で、4 本の軸を回して消す・解の一覧・蛍光・∞ など。もう一度 4D を押すと、面をたたんで普通のグラフに戻ります。
3D は x と y を両方複素数にした4次元を、床＝x（実軸・虚軸）、高さ＝y の実部、色＝y の虚部で表示します。黄＝普通のグラフ、緑＝x が複素数でも y が実数になる所、●＝解（グラフと同じ色）。上のボタンで曲面・床をオンオフ、ドラッグで回転、ホイール／ピンチで範囲を変更。
Σ は Σ(k=0,n, 式)、階乗は (2k+1)!、× は省略できます（2x, 3sin(x)）。
^ を打たなくても、1 文字の変数のすぐ後の数字は指数になります（x2 → x²、3x2-2x → 3x²−2x、a10 → a¹⁰）。i2 → i²、π2・pi2 → π²、tau2 → τ² も同じ。e2 → e² ですが、後ろに文字やかっこが続く e2x は e×2x のまま。小数は除く（x2.5 は x×2.5）。
τ（タウ）は τ か tau（τ＝2π）。e のすぐ後に i を書くと「e の i… 乗」になります（eix → e^(ix)、eiπ → e^(iπ)、eitau → e^(iτ)）。指数が式の時は今まで通り x^(2k+1)、e^x。
グラフはドラッグで移動、ホイール／ピンチで拡大、タップで値を表示。
