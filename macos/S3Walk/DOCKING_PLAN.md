# パネルのドッキング（Photoshop のような画面）の案

2026-10-26、ユーザー「Photoshop のような UI、ドッキングしたりする機能を作りたい。沢山スライダーできるから。いきなりじゃなくても考えておいて」。
まだ作っていない。作り方の案と順番のメモ。ウェブ版の共通部品 `共通部品/ui-dock/`（分離パネル・連結・タブ・端のドック・並びの保存・説明のたたみ）と考え方をそろえる。

## ねらい

- スライダーが増えても、使うものだけを見やすい所に置ける
- 景色をできるだけ広く（パネルは隠す・たたむ・浮かせる・端に寄せる）
- 並び方を「ワークスペース」として保存して、すぐ切りかえる

## 形

1. **パネルの単位**：今のインスペクターの欄を 1 枚ずつのパネルにする
   （歩く・決まった道・目印・球層・見え方・線の見え方と光・レンズ・地図・地図 2・S² の仲間・画面・コントローラー・触覚 …）
2. **置き場所**
   - 右のドック・左のドック：縦に積む。境目で高さを変える。見出しをクリックでたたむ
   - 浮かせる：Photoshop のパレットのような浮いた窓（キーを奪わない NSPanel。今の「地図を浮かせる」と同じ作り）
   - タブ：パネルの見出しを別のパネルの見出しに重ねると、1 つの枠にタブでまとまる
   - アイコンの列：たたんだドックはアイコンだけの細い列に。押すとそのパネルだけ横に開く（Photoshop の「アイコンパネル」）
3. **ドラッグの操作**
   - 見出しをドラッグして並べかえ
   - 窓の外へドラッグすると浮かせる
   - 浮いたパネルをドックの端・ほかのパネルの上・下・タブの所へ近づけると、青い線や枠で「ここにくっつく」を出す
4. **見せる・隠す**：Tab で全パネルを隠す／出す（Photoshop と同じ）、⇧Tab で右のドックだけ。メニュー「ウィンドウ」に全パネルの出し入れ
5. **ワークスペース**：並び方に名前を付けて保存・切りかえ（例：「歩く」＝パネルなし・景色だけ、「調整」＝右にスライダーを全部、「地図」＝左に地図 3 枚）。最初の並びに戻すボタン
6. **スライダー（Photoshop 風）**
   - 名前の上を左右にドラッグして値を変える（スクラブ）。⇧で 10 倍、⌥で 0.1 倍の刻み
   - 数字をクリックして直接入力、⌥クリックで初期値に戻す
   - 星を付けたスライダーを「よく使う」パネルに集める
7. **地図もパネルに**：地図 1・地図 2・S² の仲間も同じドッキングに乗せる（景色以外は全部パネル）

## 作り（SwiftUI ＋ AppKit）

- `PanelID`（列挙）と、パネルごとの中身の View を登録する表
- 並び方のモデル（Codable、UserDefaults に保存）：
  `Layout { left: [Stack], right: [Stack], floating: [Floating], collapsed: Set<PanelID> }`、
  `Stack { tabs: [PanelID], selected: PanelID, height: Double }`、`Floating { frame: CGRect, stack: Stack }`
- ドック：左右の列（HSplitView の端）に Stack を縦に積む。境目はドラッグで高さ
- ドラッグ：`.draggable`／`.dropDestination`（PanelID を Transferable に）。落とす所の案内は重ね描き
- 浮いた枠：`NSPanel`（utilityWindow・nonactivatingPanel・hidesOnDeactivate）＋ `NSHostingView`。場所は frame で保存
- キー：今と同じく景色の窓が先に受ける（パネルを触っても W・矢印などは景色へ）
