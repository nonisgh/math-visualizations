空間ベクトル 3D

書き方 ベクトル：a = (1, 2, 3)（小文字の名前）→ 原点から矢印。
点：A = (1, 0, 2)（大文字の名前）→ 点。AB と書くと A から B への矢印（B - A と同じ）。
計算：a + b（平行四辺形つき）、a - b、2a、a・b や dot(a, b)（内積となす角）、a × b や cross(a, b)（外積と平行四辺形）、|a|（大きさ）、unit(a)（単位ベクトル）、proj(a, b)（a の b への正射影）、angle(a, b)（なす角・度）。
直線：(x, y, z) = (1, 0, 0) + t(1, 2, 1)。
平面：x + 2y - z = 3（x・y・z の 1 次式）。
全角でも書けます（ａ＝（１，２，３）、× は外積、・は内積）。ドラッグで回す、ホイール・ピンチで寄る。
